# KeyLite ⌨️🖱️

**超轻量、纯原生的 macOS 键盘与鼠标按键增强助手**  
*告别笨重的 Logi Options+，享受不到 20MB 内存占用与 0% 空闲 CPU 的极致丝滑。*

---

## 🌟 为什么开发 KeyLite？

在使用罗技等第三方键盘和多按键鼠标时，官方驱动（如 Logi Options+）往往存在以下痛点：
1. **体积臃肿**：常驻后台时常占用 500MB~1GB 内存，携带大量与按键无关的分析插件与守护进程；
2. **连接不稳**：睡眠唤醒后容易假死丢配置，后台进程被系统清理后滚轮可能彻底失灵；
3. **触控板冲突**：翻转物理鼠标滚轮时，容易连带影响 MacBook 自带触控板的自然双指滑动。

**KeyLite** 为此而生：基于 Apple 官方 Swift、IOKit 与 Carbon 底层事件系统构建，100% 离线、纯本地运行、零云端遥测，专注做好按键重映射与滚轮优化。

---

## ✨ 核心特性

- **🖱️ 鼠标侧键自由映射**：精准捕获多键鼠标的侧边按键（Button 4 后退、Button 5 前进等），自由映射为任意组合快捷键、系统动作或启动指定 App。
- **🔄 鼠标滚轮独立翻转**：仅反转实体鼠标的垂直滚轮方向，**保持 MacBook 自带触控板的平滑手势体验完全不变**。
- **⌨️ 键盘功能键自由接管**：全面支持键盘 F1 ~ F12 以及右上角 PgUp / PgDn 等按键，一键绑定：
  - 🔒 **毫秒级安全锁屏**（调用系统内部入口，无 AppleScript 延迟）
  - ✂️ **微信截图 / 区域截图**
  - 🌐 **浏览器标签切换 / 页面刷新 / 撤销关闭**
  - ⌨️ **自定义录制组合键**
- **⚡ 毫秒级极速响应**：基于 `CGEventTap` 与底层事件合成，物理敲击即时触发，无卡顿。
- **🔋 极度省电与自愈机制**：
  - 空闲时 0% CPU 占用；设置窗口关闭后停止前台轮询，进入深度睡眠状态；
  - 监听系统 `didWakeNotification`，合盖睡眠、熄屏唤醒后**全自动无感自愈恢复**；
  - 进程单实例保护，避免重复多开冲突。
- **🚀 现代菜单栏常驻**：纯菜单栏（Accessory）模式，不占用 Dock 栏空间，支持 macOS 13+ 官方标准的「开机自动启动」。

## 🖥️ 系统要求

- **操作系统**：macOS 13.0 (Ventura) 或更高版本
- **硬件架构**：Apple Silicon (M1/M2/M3/M4 系列芯片) 及 Intel 架构

## 🛠️ 构建与安装

克隆仓库后，直接在终端中运行项目根目录下的构建脚本即可完成编译、代码签名并安装至系统应用程序目录：

```bash
git clone https://github.com/your-username/KeyLite.git
cd KeyLite
chmod +x build.sh
./build.sh
```

构建成功后，应用将自动部署到 `/Applications/KeyLite.app`。

## 🔐 权限配置说明

为了拦截按键并模拟快捷指令，KeyLite 需要以下两项 macOS 标准安全权限：
1. **辅助功能 (Accessibility)**：用于合成并模拟系统快捷键及锁屏等行为；
2. **输入监控 (Input Monitoring)**：用于通过底层 `CGEventTap` 捕获物理键盘与鼠标侧键输入。

> 💡 **提示**：首次打开应用时，顶部的权限指引横幅将引导你一键跳转系统设置。若曾在旧版本授权过，先关闭开关再重新开启即可刷新授权指纹。
